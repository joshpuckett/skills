# Skills

Skills for coding agents, by [Josh Puckett](https://joshpuckett.me).

## Install

```bash
npx skills@latest add joshpuckett/skills
```

This uses the open [`skills`](https://github.com/vercel-labs/skills) CLI, which needs Node 22.20 or newer. It works with Claude Code, Codex, Cursor, and most other coding agents.

## Link Previews

Gives every public page on your site its own link preview (the image people see when your link gets pasted into a message or a post), made in your site's own type and color.

Your agent drafts an image for each page using the page's own title and imagery. Then it builds a handy little tool inside your app, for local use only, where you can adjust them. You can try out different templates (or make your own), edit each one directly by typing right on the title or dragging the image around, and even add a video that plays in iMessage.

Each image is saved as a plain file, and your agent adds the tags that make links show it.

After installing, ask your agent:

```
Set up link previews for this site.
```

It works with React, Next.js, Vue, Nuxt, Svelte, SvelteKit, Astro, Remix / React Router, and plain HTML.
